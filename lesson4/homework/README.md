# ДЗ. Первый урожай

В своём форке открой [Garden.kt](src/Garden.kt). Допиши два класса: лейку и куст помидоров.

- **Лейка:** в начале две порции воды. `pour()` тратит одну, `refill()` наполняет до двух. Если воды нет, `pour()` бросает `EmptyWateringCanException`.
- **Куст:** `water(can)` берёт воду из лейки. После трёх успешных поливов созревает один помидор. Лишний полив тратит воду, но не идёт в следующий урожай.
- **Урожай:** `peek()` показывает плод или `null`, ничего не меняя. `harvest()` срывает этот же плод. Если плода нет, бросает `NoTomatoException`. Ошибка не сбрасывает рост.

Оба исключения наследуй от `IllegalStateException`. В `main()` полей куст дважды, покажи отсутствие плода через `?:` и попробуй собрать урожай. Поймай ошибку. При следующем поливе поймай ошибку пустой лейки, долей воду и повтори полив. Теперь можно сорвать помидор.

**Сдача:** сделай форк и создай в нём ветку `homework`. Сохрани решение, отправь ветку на GitHub и открой pull request: из `твой-форк:homework` в `TimofeyYA1/FD2026:main`. В PR открой **Checks → Проверка сада**. Следующие исправления пушь в ту же ветку.

**Тест локально:** выбери JDK 26 для проекта и Gradle JVM. Из корня репозитория: `./System/gradlew -p lesson4/homework test`.
